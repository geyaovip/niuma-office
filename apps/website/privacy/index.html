隐私政策

更新日期：2026 年 8 月 27 日

牛马办公重视用户的数据安全与隐私。本政策说明产品在内部体验阶段如何处理与保护数据。

我们处理的数据

为完成用户发起的任务，产品可能处理任务文本、用户主动选择的文件、任务执行状态和交付产物。未经授权，产品不主动扫描默认工作空间以外的文件。

本地数据与模型密钥

用户自定义的模型 API Key 由 macOS 系统安全能力加密保护，不上传到牛马办公云端。本地任务记录、工作空间和产物保存在用户当前电脑。

第三方模型服务

使用平台模型时，完成任务所需的内容会经牛马办公云服务转发到当前启用的模型服务；使用自定义模型时，内容会按用户配置发送到对应服务商。平台密钥不下发到客户端，自定义 API Key 不上传牛马办公云端。模型服务对相关数据的处理同时受其服务条款与隐私政策约束。

用户选择

用户可在产品内移除已保存的 API Key，并可按需删除本地任务与产物。内部体验问题请通过安装包发放渠道联系对接人。
