帮助中心

适用于牛马办公 macOS 内部体验版

如何新建任务？

在“新建任务”页输入要完成的目标即可提交；复杂任务可按需选择专家团。不选项目时，任务会使用牛马办公自动创建的默认工作空间。

任务和项目有什么区别？

任务是一次需要完成的工作；项目是可选的长期归档容器。你可以直接建任务，不需要先建项目或选择文件夹。

模型 API Key 保存在哪里？

用户自定义 API Key 在当前 Mac 上通过系统安全能力加密保护，不会作为普通文本写入工作空间或上传到云端。

结果保存在哪里？

任务产物保存在对应项目或默认工作空间的“任务” 目录中。任务完成后可从产物卡片在访达中定位。
