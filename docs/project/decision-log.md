## OpenClaw 2.0 运行时说明

- 日期：2026-09-02
- 状态：已确认
- 决策：牛马办公固定 Node `24.15.0` 与 OpenClaw `2026.8.2`，通过官方 npm 安装形态打包完整运行时，并以固定版本公开 Gateway SDK 接入。Electron 主进程只负责监督，不作为 OpenClaw 的 Node 可执行文件。
- 原因：2.0 提供可直接复用的结构化交互、持久进度、权限、凭证、自动化、搜索、子 Agent 和交互产物等底层能力；使用公开 SDK 可避免依赖安装树内部路径。
- 影响：用户无需安装 Node/OpenClaw；牛马继续拥有 Task、Project、固定专家团、渠道、凭证和界面边界。外部插件与设备能力必须经过允许列表，升级失败保留可回滚的配置与运行时版本。

## 决策传播规则

修改任一决策时，必须同时检查产品基线、UI 流程、技术基线、Backlog、Schema、API 合约和验收测试。只改一个页面或一份文档不视为决策完成。
