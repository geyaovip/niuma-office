# 牛马办公内部体验版 Backlog

详细状态只维护在当前 Story 卡中，避免在多处重复更新；本表仅用 `[done]` 标出已经完成的开发前文档工作。开始新 Story 时，从 `../stories/_template.md` 创建一张短执行卡，并更新 `current-story.md`。

## M0 开发基线

- `XB-001` `[done]` 建立文档权威顺序、决策记录和验收边界。
- `XB-002` 将已确定的星形负空间 Logo 方向完成矢量母版、字标、应用图标、品牌 Token 与客户端/官网视觉基线。
- `XB-003` 建立 Monorepo、检查脚本和共享 Contract。
- `XB-004` `[done]` 维护根 README、最小上下文路由和自动文档一致性检查。

阶段出口：无产品阻塞问题；开发者能从一个 Story 定位到唯一主文档和验收标准。

- `XB-103` Runtime Adapter 与事件归一化。
- `XB-104` 单 Task 流式执行、停止、失败和恢复。
- `XB-105` 权限模式、授权生命周期和高风险操作确认。
- `XB-106` 文件 Artifact 创建、预览、打开和 Finder 定位。
- `XB-107` 默认 Workspace 自动创建、自定义目录、授权恢复和默认根目录设置。
- `XB-108` OpenClaw 2.0 全能力基线迁移、公开 SDK、能力适配与回滚。

阶段出口：不登录、不依赖消息渠道，用户可以在 Mac 上交付一个真实文件成果。
