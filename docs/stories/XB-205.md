# XB-205：固定专家团详情、成员运行与团长汇总

- 状态：`done`
- 主文档：`docs/product/ui-and-flows.md` 第 5–6、11–12 节
- 关联决策：`D-011`、`D-018`

## 目标

让用户选择一个平台固定专家团后，能够理解长期成员与职责，并看到每位成员独立执行、输出和负责人最终汇总的真实过程。

## 范围

- 必须实现：专家团目录和详情，展示固定成员、职责、协作方式、能力边界与权限范围。
- 必须实现：每位固定成员独立运行并保存输出，负责人读取全部成员结果后完成最终汇总。
- 必须实现：执行页成员状态、输出查看、失败/停止/重试/恢复，以及产物来源追踪。
- 明确不做：临时成员、运行时动态招募、公开团队市场、用户自建专家团、付费与评分。

## 契约变化

- Schema / Event：Task 保存专家团版本快照与固定成员快照；成员运行事件和汇总运行可独立追踪。
- Permission：所有成员共用 Task 权限模式，成员不得扩大已展示的权限范围。

## 验收

- 不选择专家团时不创建成员运行；从目录选择后，新任务准确显示该专家团。
- 详情展示的成员、职责、顺序与执行时使用的快照一致；历史 Task 不受后续目录调整影响。
- 每位成员独立运行并可查看输出；负责人只在成员完成后汇总，失败和停止不会产生假完成结果。
- 重试当前轮不会重复或改写历史轮次，最终产物可追溯到专家团及其版本。
- 单元、持久化、执行集成和真实 macOS 专家团路径验证通过。

## 验证命令

- `npm run check`
- `npm run test:desktop`
- `./script/build_and_run.sh --verify`

## 完成记录

- 已完成专家团目录到正式详情页的闭环，展示稳定版本、固定成员顺序、职责、协作能力与实际权限范围；从详情进入新任务会准确预选对应专家团。
- Task 与 Turn 保存完整专家团及成员快照；执行层以平台配置校验身份，依次运行所有固定成员，保存独立输出后才执行负责人汇总。
- 执行页支持展开查看各成员独立输出，停止和失败不会显示负责人假完成；最终产物记录专家团、版本与来源。
