# XB-201：应用壳层、新任务页与侧栏任务历史

- 状态：`done`
- 主文档：`docs/product/ui-and-flows.md` 第 2–4、11–12 节
- 关联决策：`D-008`、`D-016`、`D-020`

## 目标

把已具备执行能力的桌面应用收敛为正式、紧凑、可缩放且可完整键盘操作的 macOS 工作台。

## 范围

- 必须实现：灰阶应用壳层、紧凑侧栏、新任务输入、任务历史连续滚动、搜索、菜单栏命令、窗口缩放和深浅色基础能力。
- 必须实现：空、加载、离线、失败、无权限和恢复入口；清除无动作按钮、样例账号、Demo 术语和不可兑现入口。
- 明确不做：本 Story 不实现 Task 继续执行、Project 详情、专家详情、完整个人中心、渠道绑定或 Web 版工作台。

## 契约变化

- Schema / API / Event：优先复用既有 Task 与 Runtime Contract；新增界面状态时只扩展可复用的正式状态枚举。
- Permission：界面不得绕过主进程权限与 Workspace 边界。

## 验收

- 新任务页、侧栏任务历史和搜索在最小窗口、默认窗口与全屏下均可用，无蓝色导航选中和过大间距。
- 新任务默认无专家团，默认 Workspace 与 Auto 可直接提交；所有入口有真实动作或从生产构建移除。
- `⌘N`、`⌘K`、显示/隐藏侧栏、设置和停止任务具备菜单或键盘路径，焦点与 VoiceOver 名称清楚。
- 空、离线、失败、无权限和恢复状态有正式中文说明，不暴露 OpenClaw、供应商 Key 或开发术语。
- 单元/交互测试、真实 macOS 窗口交互和打包应用启动验证通过。

## 验证命令

- `npm run check`
- `npm run test:desktop`
- `npm run build:desktop`
- `./script/build_and_run.sh --verify`

- 已加入中文 macOS 应用菜单与新任务、搜索、侧栏、停止任务、设置快捷路径；搜索焦点和控件可读名称通过真实应用辅助功能树验证。
- 已移除个人中心中尚未接通的账号、通知、更新、帮助、外观和退出假按钮，只保留可执行设置与本地执行服务状态。
