# XB-304：任务产物加入资料库

- 状态：`done`
- 主文档：`docs/architecture/technical-baseline.md` 第 5 节
- 关联决策：`D-008`、`D-009`

## 目标

让用户把真实 Task 交付文件一键加入资料库，保留任务、轮次、生成者与文件来源，并在后续 Task 中安全复用。

## 范围

- 必须实现：从交付文件加入、幂等防重、真实解析状态、原产物缺失恢复、来源信息展示、重新解析、移除和后续 Task 引用。
- 必须实现：资料库记录 Artifact、Task、Turn、专家或专家团公开来源，不复制完整 Task 会话和运行日志。
- 明确不做：自动把所有产物加入资料库、修改原产物、云端同步、产物在线分享和 Office 内置编辑。

## 契约变化

- KnowledgeSource 增加不可变的 Artifact 来源快照；Artifact 加入操作返回 KnowledgeSource 列表并按 Artifact ID 幂等。

## 验收

- 同一 Artifact 重复加入只保留一条资料源，按钮与主进程都能防重。
- 产物可产生真实正文和检索结果；缺失、越界、格式不支持时显示可恢复错误，不伪造成功。
- 来源卡可追溯 Task、Turn 和生成者；资料移除不删除原产物，后续 Task 可明确选择并保存引用快照。
- 自动化、持久化和真实 macOS 交互验证通过。

## 验证命令

- `npm run check`
- `npm run test:desktop`
- `./script/build_and_run.sh --verify`

## 完成记录

- 2026-09-01 产物加入入口已改为独立 KnowledgeRepository：主进程先通过 Workspace 边界重新核验 Artifact，再按 `artifact_id` 唯一索引幂等入库并执行真实格式解析。
- KnowledgeSource 固化 Artifact、Task、Turn、专家/专家团名称与版本的公开来源快照；资料卡展示正式任务来源，后续 Task 继续使用 XB-303 的内容摘要引用快照。
- 原产物移动、删除或权限丢失时保存可恢复错误；移除资料源只删除本地索引，不删除原交付文件。旧版 workspace `knowledgeItems` 会在启动时迁移并清理，避免产生两套活跃记录。
- `npm run check` 与 60 项桌面测试通过，覆盖重复加入、来源追溯、检索、原文件保留、缺失恢复和旧记录清理；未签名 macOS 打包与真实资料库页面已通过验证。
