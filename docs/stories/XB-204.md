# XB-204：专家目录、专家详情和单专家运行

- 状态：`done`
- 主文档：`docs/product/ui-and-flows.md` 第 5–6、11–12 节
- 关联决策：`D-011`、`D-018`

## 目标

让用户能从正式专家目录了解并主动选择一个固定专家执行 Task；未选择专家时继续由牛马单助手完成。

## 范围

- 必须实现：专家目录、分类、搜索、详情、能力边界、使用入口与加载/空/失败状态。
- 必须实现：新任务明确区分“未选择”“单专家”“专家团”；单专家运行保存稳定专家身份、独立过程与交付归属。
- 必须实现：历史 Task 保存专家版本快照，目录后续调整不改变历史记录。
- 明确不做：公开专家市场、用户上传专家、付费订阅、评分评论、临时专家或运行时动态加入成员。

## 契约变化

- Schema / API / Event：Task 增加可选 ExpertSnapshot；ExpertRun 区分单专家与专家团成员运行。
- Permission：专家不能绕过 Task 权限模式；详情必须显示实际需要的能力与权限范围。

## 验收

- 新任务默认不选择专家；普通单助手路径不受影响。
- 从专家目录选择后，新任务只显示该专家，不误选专家团；执行页显示真实身份和状态。
- 单专家完成、失败、停止、恢复和继续任务时均保留身份与历史输出；产物可追溯到对应专家。
- 搜索、分类、详情和空/错状态通过键盘与真实 macOS 交互验证。
- 单元、持久化、执行集成和真实 macOS 单专家路径验证通过。

## 验证命令

- `npm run check`
- `npm run test:desktop`
- `./script/build_and_run.sh --verify`

## 完成记录

- 已完成平台专家目录、关键词搜索、无结果状态、专家/专家团二级切换、专家详情、能力与权限展示，以及从详情进入新任务的单专家预选。
- 新任务默认无专家；Task 与 Turn 保存专家身份和版本快照，单专家只运行一次并记录独立运行事件，产物保存专家来源、名称与版本。
- 单助手与固定专家团路径保持独立；无效专家标识在运行前被拒绝且不调用执行引擎。
- `npm run check` 与 34 项桌面测试通过；打包应用实际验证了专家目录、详情、“使用此专家”和 Composer 预选交互。
