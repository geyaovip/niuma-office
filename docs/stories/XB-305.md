# XB-305：本地自动化与运行恢复

- 状态：`done`
- 主文档：`docs/product/ui-and-flows.md` 第 7 节
- 关联决策：`D-008`

## 目标

让用户在 macOS 客户端创建按时间触发的工作规则，到期自动生成真实 Task，并能查看、暂停和恢复失败运行。

## 范围

- 必须实现：一次性、每天、工作日、每周和自定义天数周期；任务描述、可选专家/专家团、项目、权限和失败重试次数。
- 必须实现：持久化调度、原子领取、每次运行创建真实 Task、下一次运行、最近结果、运行历史、启停、删除确认、失败自动重试和手动重试。
- 必须实现：应用退出或电脑离线时明确不运行；恢复后每条规则最多补跑一次已错过的计划，再从当前时间计算下一次运行，避免集中补建历史 Task。
- 明确不做：云端常驻执行、事件触发、飞书/Telegram 结果通知、自然语言生成 Cron 和跨设备同步。

## 契约变化

- Schema / IPC：Automation、AutomationSchedule、AutomationRun、AutomationStatus；调度服务仅调用 Product Task/TaskExecutor，不直接调用底层运行时。

## 验收

- 五类计划能计算稳定的下一次运行；重启、唤醒和时钟跨日不重复创建 Task。
- 到期运行进入最近任务，Task 成功/失败与 AutomationRun 一致，失败按配置重试且可手动恢复。
- 暂停、恢复和删除状态真实持久化；删除规则不删除历史 Task 与已完成产物。
- 页面展示下一次运行、最近结果、失败状态、运行历史和明确离线说明，没有无响应按钮或假成功。
- 自动化、持久化和真实 macOS 交互验证通过。

## 验证命令

- `./script/build_and_run.sh --verify`
