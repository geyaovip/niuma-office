# XB-302：连接器目录、Credential 与高风险操作确认

- 状态：`done`
- 主文档：`docs/architecture/technical-baseline.md` 第 10、13 节
- 关联决策：`D-005`、`D-010`

## 目标

让用户在 macOS 客户端查看、配置、测试和停用经过审核的办公连接器，并保证 Credential 只保存在 Keychain、高风险写操作沿用 Task 权限确认。

## 范围

- 必须实现：连接器目录、分类、搜索、详情、版本、来源、License、能力、权限、连接状态和错误恢复。
- 必须实现：首版真实支持本地文件、公开网页和标准远程 MCP；飞书与 Telegram 下任务的渠道绑定归 `XB-401` 至 `XB-404`，不在此 Story 混用 Credential。
- 必须实现：Credential 写入、读取存在性、更新和删除均经主进程与 macOS 系统加密能力；Renderer、日志、任务快照和本地 JSON 不出现明文。
- 必须实现：连接测试、超时、鉴权失败、服务不可用、停用、重新连接和应用重启恢复。
- 明确不做：公开连接器市场、任意本地命令拼接、未经审核远程插件、企业微信和浏览器 Web 工作台。

## 契约变化

- Schema / IPC：ConnectorDefinition、ConnectorInstallation、CredentialPresence、ConnectionTestResult。
- Permission：读取、写入、外部发送、购买、删除和 Workspace 外访问分别声明；高风险动作必须进入既有确认链路。

## 验收

- 目录只显示真实可用或明确未连接的能力，不出现未接通按钮和假成功。
- Credential 不离开 Keychain，读取接口只返回是否存在和脱敏标识。
- 连接测试有明确进行中、成功、失败和重试状态，结果持久化但不保存敏感响应。
- 连接器停用后不可被新 Task 调用，历史 Task 保留版本与权限快照。
- 自动化、持久化、安全与真实 macOS 交互验证通过。

## 验证命令

- `npm run check`
- `npm run test:desktop`
- `./script/build_and_run.sh --verify`

## 完成记录

- 连接器目录提供本地文件、公开网页和远程 MCP 三类真实状态；详情显示固定版本、来源、License、能力与权限。
- 远程 MCP 仅接受无 URL Credential、查询参数和片段的 HTTPS 地址；完成有超时的 `initialize` 握手后才能启用，失败状态可重试且不保存服务响应原文。
- Credential 由 Electron 主进程使用 macOS 系统加密能力保存，本地 JSON、Renderer、任务快照、Prompt 与 Runtime 配置均不出现明文；更新配置可显式删除 Credential。
- 每轮 Task 保存连接器固定版本和配置摘要，执行前重新校验状态、版本、摘要及权限；停用或配置变更后旧快照不可调用。
- Runtime 只注入 Credential 环境变量，远程 MCP 工具限制为只读白名单并显式排除发送、创建、更新、写入、删除、购买和支付。
- `npm run check`、52 项桌面测试和 `./script/build_and_run.sh --verify` 通过。真实打包应用已验证连接器目录、详情、无效 HTTPS 地址错误恢复、敏感运行时文案隐藏、密码输入和最小窗口无横向溢出。
