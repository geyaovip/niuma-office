# XB-108：OpenClaw 2.0 全能力基线迁移

- 状态：`done`
- 主文档：`docs/architecture/openclaw-2-capability-map.md`
- 关联决策：`D-005`、`D-028`、`D-035`、`D-037`

## 目标

把 OpenClaw 2.0 作为牛马办公内置执行基座，优先复用其稳定原生能力，同时保持牛马办公既有产品模型、安全边界和完整品牌体验。

## 范围

- 必须实现：固定并校验 OpenClaw `2026.8.2`，保留独立可携 Node，使用公开 Gateway SDK，完成配置迁移、真实启动和回滚基线。
- 必须实现：将会话、状态、结构化提问、权限请求、凭证请求、子 Agent、自动化、搜索、进度卡、交互产物、媒体和设备能力逐项接入 Adapter；每项明确原生复用、牛马适配或自研兜底。
- 必须实现：平台模型继续使用牛马逻辑路由，避免与 OpenClaw 官方供应商插件冲突；普通用户看不到 OpenClaw、供应商、Endpoint、Key 或原生控制台。
- 必须实现：外部插件、设备能力和长期授权默认关闭，只有通过版本、License、权限和产品范围审核后才能进入允许列表。
- 明确不做：不把 OpenClaw Control UI、Workboard、原生导航或品牌直接交付给用户；不因底层支持而提前开放 Windows、云端 Agent、企业微信或未确认的公开功能。

## 契约变化

- Runtime：从深层导入 OpenClaw 安装树迁移到固定版本的公开 Gateway SDK；统一能力协商和协议版本校验。
- Event / Permission：新增结构化问题、持久进度、插件授权、凭证请求、自动化长期授权和交互产物的归一化事件。
- Provider：平台模型提供方改用牛马自有逻辑 ID，供应商实现仅存在于 Adapter/服务端配置。

## 验收

- 新运行时在打包内真实启动、通过健康检查并能完成至少一个真实 Task；旧版本状态目录可迁移或给出可恢复错误。
- 原生能力只通过 Product Service 和 Adapter 进入客户端，普通用户界面与日志不泄露 OpenClaw 或平台供应商细节。
- 结构化问题、权限拒绝、凭证缺失、子 Agent 失败、自动化离线和插件未授权均有可理解状态与恢复路径。
- 所有已完成核心 Task、专家团、知识库、自动化和渠道回归测试通过；升级失败可回退到固定旧运行时与兼容配置备份。
- macOS 未签名安装包实际运行验证通过，文档检查通过。

## 完成记录

- 已完成：运行时与 Gateway SDK 升至 `2026.8.2`，配置原子替换并保留上一有效版本。
- 已完成：进度卡、结构化提问、用户授权的本机凭证保存与强制域名约束、exec/plugin 权限、任务搜索、子 Agent 允许列表与子任务停止清理。
- 已完成：所有能力进入代码级策略表，区分原生、适配、自研接管和当前范围禁用；自动化、渠道、固定专家身份继续由牛马管理。
- 已完成：平台 Auto 不再读取客户端环境中的方舟 Key；设备签名申请两小时短时会话，OpenClaw 只接收逻辑模型 `auto` 与短时令牌，云端强制替换为后台物理模型并流式代理。Telegram 未配置时 API 可独立启动，不使用假配置。
- 已验证：未签名 arm64 应用构建并启动；89 项桌面自动化测试、8 项 API 自动化测试、SEO 检查、运行时配置校验和文档检查通过。
- 已验证：共享服务器上的牛马独立数据库、API 容器、Secret、资源限制和 `api.alipayclaw.cn` Tunnel 已上线；真实设备签名、短时会话与火山方舟模型代理闭环返回成功。正式安装包固定使用 `https://api.alipayclaw.cn`，开发环境才允许本机覆盖；客户端云请求使用 Electron 网络栈，以遵循 macOS 系统代理与 PAC 配置。
- 已验证：从真实客户端界面提交任务，经内置 OpenClaw、短时设备会话、正式 `api.alipayclaw.cn` Model Gateway 和火山方舟完成执行；客户端正确显示 `NIUMA CLOUD E2E OK`、完成状态与本地 Markdown 交付文件。
- 已修复：OpenClaw 2.0 会把会话事件规范化为 `agent:main:<sessionKey>`，且 `chat.send` 请求在事件流期间保持挂起。Adapter 现在按当前任务的规范化会话接收服务器运行标识，并以 `chat final` 作为完成信号；对应回归覆盖服务器运行标识、规范化会话和挂起请求。
- 已完成：客户端增加单实例保护，重复启动只聚焦现有窗口，避免两个进程同时操作本地 SQLite。原生 Widget 仍保持关闭，待牛马交互产物容器形成独立 Story 后再评估。
