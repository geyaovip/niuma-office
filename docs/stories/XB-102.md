# XB-102：内置 OpenClaw 运行时与进程监督

- 状态：`done`
- 主文档：`docs/architecture/technical-baseline.md` 第 3、7 节
- 关联决策：`D-005`、`D-023`、`D-028`

## 目标

让牛马办公在不依赖用户系统 Node 或全局 OpenClaw 的前提下，启动与监督完整的内置办公引擎，并为真实 Task 执行提供稳定入口。

## 范围

- 固定且校验 Node 与 OpenClaw 版本，作为 macOS 安装包 `extraResources` 交付。
- 在 Application Support 中隔离 Runtime 配置和状态，不暴露 OpenClaw 品牌、端口或原始错误。
- 实现动态本地端口、Token 鉴权、`/readyz` 健康检查、正常停止和启动失败状态。
- 将火山方舟接入点与 Keychain 密钥映射到运行时，密钥只通过子进程环境解析。
- 通过正式 CLI/Gateway 合约执行 Task，不读写 OpenClaw 私有状态结构。

## 验收

- 内置 Node 和 OpenClaw 版本校验通过。
- OpenClaw 官方配置 Schema 校验无警告。
- Gateway 真实启动后 `/readyz` 返回 200，SIGTERM/SIGINT 可正常收尾。
- 未配置模型时 Task 进入明确的可恢复错误，不显示假成功或伪造成员输出。
- 同一 Task 的并发保存不会覆盖更新状态。
- 真实方舟接入点验证将在安全配置可用后执行，不把 Key 写入仓库或测试日志。

## 完成记录

- 固定 Node `24.15.0`、OpenClaw `2026.7.1-2`，安装包内版本校验、配置无警告校验、动态端口、Token 鉴权和真实 `/readyz` 网关启动均已通过。
- Supervisor 对并发启动去重；停止时先发送 `SIGTERM`，超时后才升级为强制停止；传给子进程的环境变量改为白名单，避免泄露桌面进程中的无关 Secret。
- Task CLI 入口已支持重复运行去重、可中止执行、固定专家团成员运行、事件序列、产物事件和崩溃恢复；模型缺失时返回正式的可恢复错误。
- `npm run test:desktop` 覆盖真实网关启动/停止、固定版本、配置、并发落盘、执行事件、成员运行、重复请求、取消和恢复。
- 平台模型的生产真实回合归属 `XB-502` 云端 Model Gateway，避免把平台 Key 下发到客户端；本 Story 不以客户端直连平台 Key 作为完成条件。
