# XB-503：平台模型目录与路由后台

- 状态：`in_progress`
- 主文档：`docs/architecture/technical-baseline.md` 第 7 节“模型网关”
- 关联决策：`D-006`、`D-007`、`D-028`

## 目标

让管理员可以安全维护平台逻辑模型与火山方舟物理模型路由，而普通用户只看到 Auto 和正式开放的逻辑模型。

## 范围

- 必须实现：模型目录表、能力与价格字段、启停、排序、最低客户端版本、健康状态和 Fallback 优先级。
- 必须实现：受保护的模型创建/修改/列表接口，以及 Model Gateway 从数据库解析 Auto 路由并在配置缺失时安全拒绝。
- 明确不做：不把平台 Endpoint、Key 或物理模型 ID返回客户端；本 Story 不建设完整可视化管理后台，不接火山方舟自动同步。

## 契约变化

- Schema：新增逻辑模型与供应商路由版本数据。
- API：新增管理模型接口；公开配置只投影允许展示的逻辑模型字段。
- Gateway：从已启用且健康的路由中解析 Auto，保留环境变量路由作为显式应急回滚路径。

## 验收

- 管理员可新增、停用、排序模型并留下审计记录；非法价格、上下文限制或空路由被拒绝。
- 普通配置接口不泄露 Provider、物理模型 ID、Endpoint、Key 或内部价格。
- Auto 只选择已启用、客户端版本兼容且健康的最高优先级路由；无可用路由时明确失败。
- 单元、数据库集成与生产模型网关回归通过，并保留一键回滚到当前固定路由的能力。
