# XB-402：Telegram 私聊扫码与任务回传

- 状态：`ready`
- 主文档：`docs/product/ui-and-flows.md` 第 9–10 节
- 关联决策：`D-011`、`D-012`、`D-015`

## 目标

用户在 macOS 个人中心扫码绑定 Telegram 私聊，在 Bot 中发送工作要求后创建真实 Task，并收到可理解的状态与最终结果。

## 范围

- 必须实现：个人中心的 Telegram 连接状态、扫码会话、过期刷新、取消、成功、冲突、解绑与 Bot 被移除状态。
- 必须实现：Telegram 官方 Bot 深链二维码，`/start <pair_token>` 一次性消费，二维码不包含 Bot Token 或其他 Credential。
- 必须实现：私聊文本进入统一 ChannelEnvelope，通过同一 provider event 幂等键只创建一个 Task。
- 必须实现：Bot 回传已接收、执行中、需要用户操作、已完成或失败；长结果使用摘要与安全的产物入口。
- 本 Story 不实现群聊和 @ 触发，不修改未经只读核验的共用 Bot Webhook。

## 验收

- 绑定、过期、取消、解绑和冲突路径在真实 macOS 界面可操作，无假成功。
- Telegram Update 验证 Secret Token，拒绝非私聊、编辑重复事件和无有效绑定身份。
- 重放同一 Update 不重复创建 Task；状态与结果回传失败可重试且不重复发送。
- 通过 Adapter/Service 集成测试，并在得到真实 Bot 参数后完成私聊端到端验收。

## 验证命令

- `npm run check`
- Telegram Adapter 定向测试
- `./script/build_and_run.sh --verify`
