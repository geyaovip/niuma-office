# XB-202：Task 会话、搜索、继续任务与状态恢复

- 状态：`done`
- 主文档：`docs/product/ui-and-flows.md` 第 5、11–12 节
- 关联决策：`D-008`、`D-018`

## 目标

让用户可以在同一个 Task 中连续补充要求、查看历次结果和产物，并在应用退出或执行中断后可靠恢复。

## 范围

- 必须实现：多轮 Task 记录、继续执行、任务内搜索、运行/等待/失败/停止恢复和历史产物归属。
- 必须实现：继续任务时保留前文与历史文件上下文，禁止把底层思考、Prompt 或运行时原文暴露给普通用户。
- 明确不做：本 Story 不实现跨设备会话同步、Task 分享链接、多人同时编辑或完整产物编辑器。

## 契约变化

- Schema / API / Event：Task 新增持久化 Turn；继续执行沿用 Task ID，并为每轮生成稳定 Turn ID 与独立结果/产物关联。
- Permission：每轮继续执行仍使用 Task 当前权限模式；高风险确认不可继承为永久授权。

## 验收

- 完成的 Task 可以继续输入，新输入和新结果追加到原 Task，不创建新的侧栏任务。
- 应用重启后按顺序恢复所有 Turn、结果和产物；执行中断显示恢复原因并可重新运行当前轮。
- 任务内搜索可定位用户输入、结果摘要与产物名称；无结果状态不影响原会话。
- 停止、失败、等待确认和重试只作用于当前轮，不覆盖已经完成的历史轮次。
- 单元、持久化、执行集成和真实 macOS 多轮任务交互验证通过。

## 完成记录

- Task 已新增持久化 Turn；继续任务沿用原 Task ID，历史输入、结果、成员运行和错误状态按轮次保存。
- 每轮使用独立目录与 Artifact ID，继续执行不覆盖历史文件；运行 Prompt 只携带最近八轮的受控上下文。
- 任务页按轮次展示对话和产物，支持任务内搜索、结果定位、运行中禁用重复提交，以及只重试当前轮。
- 应用异常退出时只把当前运行轮标记为可恢复失败，既有完成轮次保持不变。
