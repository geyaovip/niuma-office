# XB-105：权限模式与高风险操作确认

- 状态：`done`
- 主文档：`docs/architecture/technical-baseline.md` 第 4、9 节
- 关联决策：`D-009`、`D-024`

## 目标

把默认工作空间内操作、工作空间外访问和高风险写操作转换为明确、可审计、可恢复的桌面权限流程。

## 范围

- 必须实现：权限模式、路径边界判定、单次/本任务授权、拒绝、超时、应用重启失效、高风险操作二次确认和审计记录。
- 必须实现：Renderer 只显示牛马权限文案；所有确认由主进程签发并校验，不接受 Renderer 自报已授权。
- 明确不做：本 Story 不实现外部消息渠道授权或连接器专属 OAuth。

## 验收

- 默认 Workspace 内的普通读写按默认权限执行；Workspace 外读取、覆盖/删除、外部发送等操作进入 `waiting_user`。
- 允许、拒绝、超时和恢复路径均可操作，且重复决议不重复执行。
- 授权范围最小化，敏感授权不跨应用重启保留；审计记录不包含文件正文或 Credential。
- 单元测试、真实 macOS 交互、打包应用启动验证通过。

## 验证命令

- `npm run check`
- `npm run test:desktop`
- `./script/build_and_run.sh --verify`

## 完成记录

- 默认工作空间启用三档权限模式：受限权限、默认权限、完全访问；模式由任务创建时固化并传给内置办公引擎。
- Gateway 权限请求只由主进程接收和决议，支持拒绝、仅允许一次、仅对当前任务放行低风险命令；应用重启、任务结束或取消后不保留任务级授权。
- 越界路径、删除、提权、外部发送和发布类操作不会被任务级授权自动放行；确认超时会自动拒绝并恢复任务状态。
- 界面展示待确认命令与位置，审计事件会对命令中的密钥、令牌和 URL 凭据脱敏，不记录文件正文或 Credential。
- 2026-08-28 已通过 20 项桌面测试、类型与文档检查；完成应用目录打包、真实启动，并在打包客户端验证三档权限选择交互。
