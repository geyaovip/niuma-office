# XB-501：云端配置与审计框架

- 状态：`in_progress`
- 主文档：`docs/architecture/technical-baseline.md` 第 12 节“部署拓扑”
- 关联决策：`D-009`、`D-020`、`D-028`

## 目标

让牛马办公的客户端公共配置、模型路由和发布状态通过独立云端配置安全下发，并为后台写操作留下可追溯审计记录。

## 范围

- 必须实现：独立 PostgreSQL 配置与审计表、公开只读配置接口、受保护的管理写接口、版本/ETag、幂等写入和回滚所需的历史快照。
- 必须实现：平台模型、渠道和发布功能的公开状态不暴露供应商 Key、Endpoint、服务器路径或开发术语；配置缺失时返回稳定保守默认值。
- 明确不做：本 Story 不建设完整管理后台界面，不接邮箱管理员登录，不配置飞书或 Telegram 账号，不实现多模型 Fallback。

## 契约变化

- Schema：新增公共配置、配置版本和审计事件表。
- API：新增公开配置读取接口与只允许管理凭证访问的配置写入/历史接口。
- Security：管理凭证只从 Secret 文件加载，日志与响应不得返回凭证原文。

## 验收

- 未鉴权客户端只能读取允许公开的版本化配置，响应支持 ETag/304，数据库不可用时不返回假成功。
- 管理写操作具备鉴权、输入校验、幂等键和审计记录；重复请求不产生重复版本。
- 配置历史可读取且包含操作者、时间、变更摘要和前后版本，不记录 Secret。
- API 单元与 PostgreSQL 集成测试、生产部署健康检查和原有模型网关/渠道接口回归通过。
