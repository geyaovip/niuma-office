# XB-107：默认工作空间与自定义目录

- 状态：`done`
- 主文档：`docs/product/product-baseline.md` 第 7 节
- 关联决策：`D-009`、`D-024`

## 目标

让 Task 和 Project 在用户不选择文件夹时自动使用正式默认工作空间，同时支持安全切换默认根目录和为单个项目选择现有文件夹。

## 范围

- 必须实现：首次启动自动创建默认根目录、Task/Project 自动子目录、自定义默认根目录、项目现有目录、持久授权与失效恢复。
- 必须实现：设置页展示当前目录并允许在访达打开；更改默认根目录不静默移动历史任务、项目或产物。
- 明确不做：本 Story 不实现云盘同步、多人共享目录或历史数据批量迁移。

## 契约变化

- Schema / API：新增工作空间设置与项目目录选择接口；历史项目继续保存自己的绝对路径。
- Permission：目录必须来自系统文件夹选择器；主进程校验存在性、可访问性和书签/授权状态，Renderer 不可自报任意根目录。

## 验收

- 全新安装无需选择目录即可创建 Task 和 Project，目录结构稳定且不在应用包或临时目录中。
- 修改默认根目录后仅影响新建内容，历史 Task/Project/Artifact 仍指向原目录。
- 单个项目可使用用户选择的现有目录；取消选择不会创建半成品项目。
- 目录被移走、撤销授权或不可写时给出恢复选择，不崩溃、不静默回退到其他路径。
- 单元测试、真实 macOS 文件夹选择交互和打包应用启动验证通过。

## 验证命令

- `npm run check`
- `npm run test:desktop`
- `./script/build_and_run.sh --verify`

- Renderer 只能调用主进程系统文件夹选择器；主进程校验目录存在、可读写，并保持历史 Task/Project/Artifact 原路径不被默认根目录切换影响。
