# XB-106：文件产物创建、预览与复用

- 状态：`done`
- 主文档：`docs/product/product-baseline.md` 第 5.1、6.2 节
- 关联决策：`D-007`、`D-009`

## 目标

让用户在任务完成后直接查看、打开和定位真实交付文件，并可把文件继续用于新任务或加入资料库。

## 范围

- 必须实现：结构化 Artifact 记录、真实文件校验、Markdown/TXT/PDF/图片安全预览、系统默认应用打开和访达定位。
- 必须实现：从 Artifact 发起后续任务、加入资料库；文件缺失、格式不支持和路径越界时给出正式恢复提示。
- 明确不做：本 Story 不实现 Word/Excel/PPT 的完整在线编辑，也不实现云端知识库解析。

## 契约变化

- Schema / API / Event：新增 Artifact 元数据、列表、预览与复用接口；保留现有 `artifact.created` 运行事件兼容性。
- Permission：Renderer 不能传任意路径读取文件，主进程只接受已登记 Artifact 的 ID，并再次校验工作空间边界。

## 验收

- 任务交付文件被登记为 Artifact，重启应用后仍能从对应任务查看。
- 支持的格式可在应用内预览；所有格式均可调用系统默认应用打开和在访达中定位。
- Artifact 可作为附件发起新任务，也可加入资料库；重复操作不产生重复记录。
- 文件被移动、删除、损坏或越界时不崩溃、不泄露本机路径，并提供定位或重新生成路径。
- 单元测试、真实 macOS 交互和打包应用启动验证通过。

## 验证命令

- `npm run check`
- `npm run test:desktop`
- `./script/build_and_run.sh --verify`

## 完成记录

- 任务完成后以结构化 Artifact 记录文件名称、格式、大小、来源任务与创建时间；旧数据可无损兼容，新增记录原子写入。
- Renderer 只传 Artifact ID；主进程在每次预览、打开和定位前重新检查真实文件、任务归属、工作空间边界与软链接，越界、缺失和损坏路径不会泄露给界面。
- Markdown/TXT/JSON 等文本、常见图片和 PDF 支持安全预览；其他格式使用系统默认应用，所有格式均可在访达定位。
- 产物可作为可信附件继续发起新任务，并可幂等加入资料库；资料库展示真实来源文件，不提供虚假导入入口。
- 2026-08-28 已通过 22 项桌面测试、类型与文档检查、应用目录打包和真实启动；在打包客户端完成预览、加入资料库及继续用于新任务的全链路交互验收，验收数据随后已清理。
