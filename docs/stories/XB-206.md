# XB-206：个人中心、外观与本地数据管理

- 状态：`done`
- 主文档：`docs/product/ui-and-flows.md` 第 8、11–12 节
- 关联决策：`D-003`、`D-007`、`D-015`

## 目标

让内部体验用户从侧栏底部打开正式个人中心，查看本地身份、执行服务、外观、工作空间、本地数据与版本状态，并完成范围内的真实设置操作。

## 范围

- 必须实现：紧凑个人中心浮层、本地体验身份、设置入口、外观模式、本地执行服务状态、工作空间与本地数据目录、帮助反馈、检查更新。
- 必须实现：浅色、深色、跟随系统持久化并立即生效；数据目录可在访达中定位，存储占用显示真实值。
- 必须实现：不可用、无权限、检查失败和恢复状态，不展示升级、积分、邀请、签到或虚构账号权益。
- 明确不做：邮箱登录、退出登录、付费升级、公开版本自动更新和消息渠道绑定；这些由后续 Story 完成。

## 契约变化

- IPC / Persistence：新增外观偏好、数据目录信息、存储占用、访达定位和内部版本检查结果。
- Permission：只允许打开牛马自己的数据目录；不得通过该入口浏览任意路径。

## 验收

- 个人中心内容、分组、间距和状态信息通过真实 macOS 交互验证，无 Demo 文案和无效按钮。
- 三种外观模式可切换、持久化并响应系统变化，所有核心页面仍清晰可用。
- 本地执行服务、默认工作空间、本地数据路径和真实占用显示正确；目录打开失败时有明确恢复提示。
- 内部版本检查有真实检查、当前已是最新、检查失败和重试状态，不伪造远端新版本。
- 单元、IPC 集成和真实 macOS 路径验证通过。
