# XB-600：正式官网与首版 SEO

- 状态：`blocked`
- 主文档：`docs/product/website.md`
- 关联决策：`D-017`、`D-021`、`D-025`、`D-032`、`D-036`

## 目标

让访客通过 `alipayclaw.cn` 准确理解牛马办公、查看真实安全与使用信息，并获得可校验的 macOS 内部体验包。

## 范围

- 必须实现：首页、下载、指南、安全、隐私、协议、反馈、版本记录和正式 404；响应式、键盘可用、静态 HTML、页面级 Metadata、Canonical、Open Graph、JSON-LD、站点地图与索引控制一次完成。
- 必须实现：下载信息来自服务器受控版本清单，显示真实版本、架构、未签名状态、文件大小和 SHA-256；根域名发布，`www` 永久跳转根域名。
- 明确不做：不建设 Web 任务工作台，不宣传飞书、Telegram、登录或其他尚未通过正式验收的能力，不放置假反馈表单和失效下载按钮。

## 契约变化

- Website：新增 `/guide`、`/security`、`/feedback`、`/releases` 和 `404.html` 静态路由。
- Release：新增服务器版本清单与安装包静态发布契约；不使用 R2。

## 验收

- 全部公开路由直接访问返回正确状态，正文存在于初始 HTML，根域名 Canonical、内部链接、404 和 `www` 跳转正确。
- 下载页只在版本清单和文件均可用时提供下载，并准确展示未签名安装说明、系统要求、大小与 SHA-256；异常时不假成功。
- 桌面与移动端布局、键盘焦点、Reduce Motion、结构化数据、站点地图、robots、抓取 HTML 和 Core Web Vitals 基线通过验证。
- 所有公开文案逐字检查，不含 Web 工作台、占位内容、虚构数据、未上线能力或开发术语。

- `npm --workspace @niuma/website run check`
