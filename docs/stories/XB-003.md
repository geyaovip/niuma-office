# XB-003：建立正式 Monorepo 与共享基线

- 状态：`completed`
- 主文档：`docs/architecture/technical-baseline.md` 第 1–5 节
- 关联决策：`D-005`、`D-018`、`D-019`、`D-020`、`D-022`、`D-023`

## 目标

建立可运行、可测试、可打包的正式工程，使后续功能在统一契约、品牌 Token 和安全边界上开发。

## 范围

- 必须实现：根工作区、Electron macOS 客户端、TypeScript 严格模式、基础测试、共享契约入口、正式设计 Token、开发与构建命令。
- 明确不做：本 Story 不完成 OpenClaw、云端服务和外部渠道业务逻辑。

## 契约变化

- 建立 Desktop Preload 最小安全 API；渲染层不获得 Node 权限。
- 建立后续 Task、Project、Expert、Artifact 和 Runtime Event 的共享 Schema 包。

## 验收

- 桌面客户端能在 macOS 真实窗口启动并显示正式壳层。
- TypeScript 检查、单元测试和生产构建通过。
- Renderer 无 Node Integration，Preload 只暴露白名单能力。
- 品牌 Token 和核心对象 Schema 可从共享包导入。

## 验证命令

- `npm run check`
- `npm run build:desktop`
- `npm run test:desktop`

## 完成记录

- 已建立 npm Workspaces Monorepo，包含 Desktop、Website、Contracts 与 UI Token 包。
- Electron 客户端已在真实 macOS 窗口运行，Renderer 保持 Sandbox + Context Isolation，只通过 Preload 白名单访问主进程。
- `npm run check`、`npm run test:desktop`、`npm run build:desktop`、`npm run build:website` 通过；npm audit 高风险阈值为 0。
- 设计基线通过真实浏览器和打包应用双重验证；后续功能进入 `XB-102`。
