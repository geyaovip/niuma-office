# XB-301：Skill 目录、安装与风险检查

- 状态：`done`
- 主文档：`docs/architecture/technical-baseline.md` 第 9、12 节
- 关联决策：`D-005`、`D-010`

## 目标

让用户查看平台提供的 Skill，并在明确来源、版本、License、依赖与权限后受控安装或停用，安装结果能真实参与 Task 执行。

## 范围

- 必须实现：Skill 目录、分类、搜索、详情、已安装状态、版本、来源、License、能力说明和权限清单。
- 必须实现：安装前固定版本并检查清单、依赖、路径与风险；安装、停用、失败、重试和升级状态持久化。
- 必须实现：已安装 Skill 可从 Composer 通过 `/` 选择并注入 Task 快照，执行层只加载该版本。
- 明确不做：公开投稿市场、付费、评分、任意脚本粘贴执行或未审核远程自动更新。

## 契约变化

- Schema / IPC：新增 SkillDefinition、SkillInstallation、TaskSkillSnapshot 与安装事件。
- Permission：Skill 权限不得超过 Task 权限；涉及命令、网络、外部发送和 Workspace 外路径必须按现有权限规则确认。

## 验收

- 未安装 Skill 不可被 Task 调用；安装前显示真实来源、版本、License、依赖和权限。
- 安装路径固定在牛马数据目录，拒绝路径穿越、未知清单字段、未固定版本和无 License 的外部包。
- 安装、停用、失败和重试状态可恢复；历史 Task 保留 Skill 版本快照。
- Composer 可选择已安装 Skill，执行 Prompt 和事件能证明只加载该快照。
- 单元、持久化、执行集成和真实 macOS 路径验证通过。

## 验证命令

- `npm run check`
- `npm run test:desktop`
- `./script/build_and_run.sh --verify`

## 完成记录

- 新增 5 个经过审核的内置 Skill，目录提供分类、搜索、详情、来源、固定版本、License、能力、依赖、权限和安装状态。
- 安装文件与状态分别持久化到牛马数据目录，支持安装、停用、重新启用、失败记录、重试和版本升级来源记录；严格拒绝未知技能、清单未知字段、浮动版本和入口路径越界。
- Composer 支持按钮或输入 `/` 打开已安装 Skill 选择器，每轮最多选择 5 个；Task 与历史轮次保存固定版本及指令摘要快照。
- 执行前按 ID、版本、摘要、启用状态和本轮权限重新核验，仅将匹配的 Skill 指令注入单助手、单专家、固定专家团成员和负责人汇总 Prompt。
- `npm run check`、43 项桌面测试和 macOS 打包通过；在真实打包应用中完成技能详情、安装状态恢复、深色模式和 `/` 选择路径验证。签名因本机没有有效 Developer ID Application 证书继续归属 `XB-605`。
