# XB-103：Runtime Adapter 与事件归一化

- 状态：`done`
- 主文档：`docs/architecture/technical-baseline.md` 第 1、3、11 节
- 关联决策：`D-005`、`D-028`

## 目标

让主进程和界面只依赖牛马自己的任务、成员、工具、权限与产物事件，不依赖 OpenClaw 私有输出或错误文本。

## 范围

- 必须实现：事件 Schema 校验、任务内严格递增序列、重复事件幂等、运行时错误归一化、任务订阅和历史重放。
- 明确不做：本 Story 不接入生产云端模型、外部消息渠道或新的 UI 页面。

## 契约变化

- `RuntimeEvent` 成为主进程、持久化和 Renderer 之间的唯一执行事件结构。
- Preload 只暴露读取已归一化事件和订阅新事件的白名单接口。

## 验收

- 同一 Task 的事件序列从 0 严格递增，重复事件不会产生第二条记录。
- Renderer 重开任务时可以读取历史事件，并继续接收新事件。
- OpenClaw/Provider 原始错误不会直接进入用户可见文案，脱敏诊断保留在本地。
- Schema、幂等、重放和订阅测试通过。

## 验证命令

- `npm run check`
- `npm run test:desktop`
- `./script/build_and_run.sh --verify`

## 完成记录

- `RuntimeEvent` 已成为主进程、持久化与 Renderer 之间的统一执行事件结构，并由共享 Schema 校验。
- 每个任务的事件序列严格递增；带去重键的重复事件不会重复落盘；任务重开后可读取历史并继续订阅实时事件。
- Provider/OpenClaw 原始错误仅写入脱敏后的本地诊断日志，界面只显示正式、可恢复的错误文案。
- 2026-08-27 已通过类型检查、14 项桌面测试、Renderer/Electron 构建及真实 macOS 应用目录打包启动验证。
