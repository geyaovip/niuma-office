# XB-104：Gateway 实时执行与可取消任务

- 状态：`done`
- 主文档：`docs/architecture/technical-baseline.md` 第 3、4、7 节
- 关联决策：`D-005`、`D-028`

## 目标

让桌面端通过内置办公引擎的 Gateway 会话执行任务，实时接收正文与工具状态，并能可靠取消，不再依赖只能在结束后返回整段结果的 CLI 子进程。

## 范围

- 必须实现：Gateway 鉴权连接、幂等发送、增量正文、工具开始/完成/失败事件、运行取消、连接关闭恢复与超时处理。
- 必须保留：内置办公引擎继续对用户隐藏；Gateway Token 不进入 Renderer、日志或命令行参数。
- 明确不做：本 Story 不接入生产云端模型网关、飞书或 Telegram。

## 验收

- `chat.send` 成功确认后，正文增量能够实时更新当前任务；最终结果与本地 Markdown 产物一致。
- 工具事件被归一化为牛马自己的 `tool.started`、`tool.completed`、`tool.failed` 事件。
- 用户停止任务会调用 `chat.abort`，只产生一次 `task.cancelled`，不会在后台继续运行。
- 连接关闭、超时、Gateway 错误均进入正式错误与可重试路径，不暴露 Token 或 OpenClaw 私有文本。
- 单元测试、真实 Gateway 启停测试、打包应用启动验证通过。

## 验证命令

- `npm run check`
- `npm run test:desktop`
- `./script/build_and_run.sh --verify`

## 完成记录

- 桌面主进程通过带 Token 的本地后端身份连接内置 Gateway，Token 不进入 Renderer、日志或命令行参数。
- 任务使用幂等 `chat.send`，正文增量实时更新界面，最终正文保存为完整 Markdown 产物。
- Gateway 工具流已归一化为 `tool.started/completed/failed`；重复事件按运行与工具调用键去重。
- 停止任务会调用 `chat.abort` 并结束本地等待；断连、超时与 Gateway 错误进入脱敏、可重试路径。
- 2026-08-28 已通过 16 项桌面测试，其中包含真实内置 Gateway 鉴权握手与状态请求；类型检查、构建、应用目录打包和真实启动验证通过。
