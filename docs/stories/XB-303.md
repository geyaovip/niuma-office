# XB-303：知识库解析、检索与任务引用

- 状态：`done`
- 主文档：`docs/architecture/technical-baseline.md` 第 5、13 节
- 关联决策：`D-008`、`D-009`

## 目标

让用户在 macOS 客户端把 PDF、Word、Markdown、TXT 文件或公开网页加入本地资料库，看到真实解析状态，并能在 Task 中主动引用可追溯的知识片段。

## 范围

- 必须实现：资料库、资料源和片段的本地持久化；文件与网页来源分开记录，原文件不复制到会话目录。
- 必须实现：PDF、DOCX、Markdown、TXT 和公开网页正文解析；每种格式都有大小、页数或正文长度限制及明确失败原因。
- 必须实现：标题、来源、更新时间、解析状态、片段数量、失败重试、移除和应用重启恢复。
- 必须实现：本地全文检索、Task Composer 主动选择资料、每轮引用快照、Prompt 注入及结果中的来源标识。
- 必须实现：Workspace、Task 会话、Knowledge、Memory 和 Credential 继续分开存储；知识库内容不上传云端。
- 明确不做：OCR、扫描件识别、音视频、复杂 Excel 表格解析、自动抓取登录网页、云端向量库和完整 Office 内置编辑。

## 契约变化

- Schema / IPC：KnowledgeBase、KnowledgeSource、KnowledgeChunk、KnowledgeReference、ParseResult、SearchResult。
- Task：每轮保存所选资料源与片段摘要；历史引用不随重新解析静默改变。

## 验收

- 五类来源均能产生真实正文或明确失败，不使用占位解析结果。
- 搜索只返回当前知识库已完成解析的片段，结果包含来源、位置与匹配摘要。
- Task 只注入用户主动选择且执行前重新核验的引用，产物可追溯到资料源。
- 移除资料后新 Task 不可引用；历史 Task 仍保留公开引用快照但不复制完整敏感正文。
- 自动化、持久化、安全与真实 macOS 交互验证通过。

## 验证命令

- `npm run check`
- `npm run test:desktop`
- `./script/build_and_run.sh --verify`
