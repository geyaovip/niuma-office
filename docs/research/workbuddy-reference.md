# WorkBuddy 产品体验对照

## 1. 取证边界

- 走查日期：2026-08-27。
- 参考对象：`https://www.workbuddy.cn/app` 已登录网页端、用户提供的 WorkBuddy v5.3.14 客户端截图、已安装客户端的可见页面。
- 仅记录公开可见的产品结构、交互和视觉规律；不记录账号隐私、历史任务正文、密钥或内部实现猜测。
- 本文是设计参考，不是复制清单；牛马办公只实现自身已确认范围。

## 2. 应用壳层

- 左侧栏约占窗口 18%–20%，浅灰底，主内容白底，边界靠明度区分而非彩色描边。
- 导航行高紧凑，选中态为浅灰块、黑色文字和线性图标；品牌色只出现在 Logo 或极少状态反馈。
- 顶部只有折叠、搜索等轻量工具；任务历史直接在侧栏按最近活动排序，不跳转独立任务中心。
- 账号入口固定在左下角，点击后向上展开紧凑浮层，不占用完整页面。

## 3. 新建任务

- 首页中心由产品问候、场景切换、任务类型快捷项和大输入框组成，没有营销 Banner。
- 输入框底部承载文件、工作空间、权限、模型和发送；未选择工作空间时仍可直接提交。
- 模型入口默认显示 `Auto`，展开后显示产品化模型名称、能力或消耗信息，不暴露平台供应商、Endpoint 或平台密钥。
- 默认输入区没有专家团 Chip。用户从专家团目录主动选择后，团队才进入当前任务上下文。

## 4. 模型与设置

- 平台模型属于产品能力，普通用户只选择 `Auto` 或模型名，不参与平台接入配置。
- 自定义模型是设置中的独立高级能力：用户明确添加提供商、API Key 和模型名。
- 自定义密钥状态与平台模型状态分开表达，不能把“平台服务是否可用”等同于“用户是否填写 Key”。
- 设置采用大尺寸双栏浮层：左侧分类，右侧内容；账号浮层只保留入口，不塞入复杂表单。

## 5. 专家、技能与连接器

- 一个一级入口承载 `专家 / 技能 / 连接器` 顶部 Tab；专家页再区分单专家与专家团。
- 专家团是可复用的固定团队，卡片说明成员数量、职责与适用场景；用户主动“使用/召唤”后进入任务。
- 专家团运行展示固定成员状态和独立输出，再由负责人汇总；不能临时生成未展示成员。
- 技能与连接器采用目录卡片，但安装、授权、连接必须有真实状态和恢复路径。

## 6. 项目与任务详情

- Project 是可选组织容器；项目页提供已有项目、搜索、新建和模板入口，不阻塞独立任务。
- 任务详情以对话时间线为主，底部输入框持续可用；右侧可选详情栏用于概览、产物和引用。
- 任务行支持置顶、归档等就地操作；任务输出区强调最终结果和文件产物，底层运行日志降权。

## 7. 牛马办公采用项

- 采用：灰阶桌面工作台、紧凑侧栏、任务即入口、可选 Project、输入框内模型入口、设置中独立自定义模型、专家团显式选择、固定成员可见。
- 保留差异：用户确认的黄色牛品牌形象、牛马办公名称与文案、飞书/Telegram 渠道、本地 OpenClaw Runtime、默认 Workspace 和自身权限规则。
- 不采用：WorkBuddy 品牌绿色、机器人素材、积分/升级/广告、助理、空间、灵感、“更多”、腾讯专属生态文案和任何第三方专有资产。

## 8. 实现验收清单

- 侧栏选中态无蓝色，导航行高、分组间距和任务行密度与参考接近。
- 除 Logo 和必要状态色外，客户端主交互使用黑白灰；不可用彩色渐变填充页面。
- 新用户进入新任务页时 `teamId` 为空；只有明确选择专家团后才创建 `ExpertRun`。
- 普通用户界面不得出现火山方舟平台 Endpoint、平台 API Key 或 OpenClaw 名称。
- 自定义模型入口说明“使用自己的额度”，密钥只在本机安全存储。
- 普通任务与专家团任务都必须真实执行、可停止、可恢复并保存产物。
