# 牛马办公内部体验版产品执行基线

正式 Slogan：**专门替“牛马”干活的 AI 办公工具**。

## 1. 产品目标

牛马办公不是聊天机器人，而是让用户把真实工作交给 AI 并获得可直接使用成果的 macOS 工作平台。

核心闭环：

```text
新建 Task
→ 可选 Project / 专家 / 固定专家团 / Skill / 连接器 / 知识库
→ 自动使用默认 Workspace；用户可选自定义目录
→ 选择权限模式
→ 内置 OpenClaw 在本机执行
→ 展示计划、成员进度、工具动作与必要确认
→ 交付结果和文件型产物
→ 保存任务历史
→ 可继续追问、转入项目、加入知识库或设置自动化
```

## 2. 当前发布范围

- 平台：macOS，优先 Apple Silicon；Intel 构建是否保留在发布前根据实际测试决定。
- 发布性质：先以内部体验方式分发，但所有纳入范围的功能按正式客户交付标准建设；“内部体验版”不是 Demo、原型或低质量临时版本。
- 对外载体：macOS 客户端、正式官网、指南、安全与版本页面，以及支撑它们的必要云端服务。
- Web 边界：官网无需登录，只负责介绍、下载、指南、安全和版本信息，不设置用户协议、隐私政策、公开联系方式、ICP备案展示或在线任务工作台；所有功能交互均在 macOS 客户端实现。
- 身份：开发期使用本地单用户身份；邮箱 OTP 登录最后接入 Resend。
- Runtime：OpenClaw 随安装包交付并完全隐藏。
- 模型：平台模型统一走火山方舟；支持用户自定义 API Key。
- 消息渠道：飞书、Telegram；支持私聊和群聊 `@牛马`。
- 执行位置：Agent 只在用户 Mac 上运行；云端只做账号、模型网关、目录、消息中继、离线队列和管理。

## 3. 核心对象

- `Project`：长期目标、项目说明、资料和文件型产物的可选容器。
- `Task`：独立工作单元，可不属于任何 Project。
- `Workspace`：Task 或 Project 的文件资料与产物目录；系统始终提供默认目录，用户无需先选择文件夹。
- `Expert`：固定的角色、指令、推荐模型、Skill 和连接器组合。
- `ExpertTeam`：固定团长、固定成员、固定职责及协作规则的团队模板。
- `ExpertRun`：某个固定专家在一次 Task 中的执行记录，不是临时成员。
- `Skill`：告诉 AI 如何完成一类工作。
- `Connector`：连接外部系统的能力，包括 MCP 和平台渠道能力。
- `KnowledgeBase`：用户明确选择长期参考的资料集合。
- `Memory`：从长期交互中提炼的用户偏好和稳定事实。
- `Artifact`：Task 生成的文档、表格、PPT、图片、HTML、代码等文件成果。
- `Automation`：按时间触发并创建 Task 的规则。
- `ChannelBinding`：飞书或 Telegram 身份与牛马设备/账号的安全绑定。

## 4. 导航与任务组织

左侧固定区域按以下顺序展示：

```text
+ 新任务
项目
专家·技能·连接器
自动化
知识库

最近任务（按最近活动时间倒序）
Task A
Task B
Task C
……向下滚动加载更早任务

项目快捷入口
Project A
Project B

底部：个人中心 / 通知 / 设备与渠道状态
```

当前不提供：助理、空间、灵感、“更多”一级导航、独立全部任务页。任务列表在侧栏连续滚动，支持搜索和状态筛选，但不跳转到另一套任务中心。

## 5. 专家与专家团

### 单专家

专家包含名称、头像、简介、分类、适用场景、固定角色指令、推荐模型、Skill、连接器、知识库绑定、来源、License 和版本。

### 固定专家团

- 用户从专家团列表选择一个已有团队。
- 默认不选择专家团；未选择时任务由单助手执行，不创建任何虚假的成员运行。
- 团长和成员都是持久配置，不允许任务运行时悄悄增加未展示成员。
- 团长拆解任务并把子任务分派给固定成员。
- 每位成员拥有独立 `ExpertRun`、状态、消耗、过程摘要和输出。
- 用户可以展开查看成员结果，也可以只看团长汇总。
- 顺序与并行均由团队模板配置；失败成员可单独重试。
- 最终交付必须说明各成员贡献及未完成部分。

## 6. 模型产品策略

客户端只显示平台定义的逻辑模型，不写死供应商版本：

- `Auto`：根据任务能力、成本、上下文和可用性路由。
- `旗舰`：复杂办公、规划和多模态理解。
- `轻量`：普通问答、摘要、分类和低延迟任务。
- `深度推理`：复杂分析、研究和专家团团长任务。
- `代码`：代码生成、调试和工程任务。

内部版在火山方舟开通列表中选择对应豆包旗舰、豆包轻量、DeepSeek/推理和代码模型。后台可新增、停用、排序、修改价格和能力标签；客户端不发版即可生效。

平台供应商、Endpoint 和平台 Key 只存在服务端与管理后台，普通用户不得在客户端看到。用户自定义模型支持预设供应商与 OpenAI 兼容配置，并作为独立高级设置出现；自定义 Key 仅存在本机，使用自定义模型时不经过平台模型网关计费。

## 7. 文件、知识和产物

- 创建独立 Task 时不弹出强制选目录；未选择时自动在牛马默认根目录下创建独立 Workspace。
- 创建 Project 时同样不强制选目录；未选择时自动创建 Project Workspace。
- 项目内 Task 默认继承 Project Workspace，不再重复询问目录。
- 用户可以在创建前或设置中选择现有文件夹作为自定义 Workspace；该选择是增强项，不是前置条件。
- 默认根目录可在个人设置中修改，但不得静默移动历史 Task 或 Project 的文件。
- Task、Session、Message 和 Execution Log 存在 SQLite，不作为项目文件写入。
- 知识库首版支持 PDF、Word、Markdown、TXT 和普通网页正文。
- 首版不支持扫描件 OCR、音视频解析和复杂表格语义索引。
- 产物支持预览、系统打开、在 Finder 定位、继续作为任务输入和加入知识库。
- 首版不内置完整 Word、Excel 或 PPT 编辑器。

## 8. 权限模式

- `受限`：只读当前默认或自定义 Workspace；任何写入、Shell、浏览器操作和外部调用均确认。
- `默认`：允许在当前 Workspace 内读取、创建和修改普通文件；删除、覆盖重要文件、访问外部路径、发送消息和高风险连接器操作确认。
- `完全访问`：允许当前 Task 在用户明确授权范围内执行 Shell、浏览器和文件操作；删除、购买、对外发布、发送消息及不可逆操作仍需确认。

授权可以是“仅本次操作”或“本次任务”。不得提供永久跳过所有高风险确认的开关。

## 9. 当前明确不做

- Windows 客户端
- 企业微信和个人微信渠道
- Cloud Agent Runtime 或电脑关机后在云端继续执行
- 公开付费、订单、退款和复杂套餐
- 用户公开创作者市场和收益分成
- 多人项目协作和企业组织权限
- 完整跨设备文件、聊天和知识库同步
- 助理、空间、灵感、广告和成长任务
- 完整 Office 内置编辑器
- 未确认价格、套餐、积分、促销、邀请和增长活动
- Web 版任务工作台或浏览器在线使用入口

## 10. 内部版核心验收

用户可以从正式官网准确理解产品能力、系统要求、数据边界和下载方式；安装后在 Mac 上创建一个真实 Task，无需选择文件夹即可使用默认 Workspace，也可改用自定义目录。选择权限、专家或固定专家团后，由隐藏的 OpenClaw 在本机执行并获得可打开的结果文件。任务过程可恢复、成员输出可查看；用户也可以通过已扫码绑定的飞书或 Telegram 下任务，在设备离线时看到排队状态，并在 Mac 恢复在线后自动执行与回传结果。全程不得出现占位文案、虚构结果、无效入口或仅供演示的数据路径。
