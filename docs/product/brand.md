# 牛马办公品牌基线

## 1. 品牌方向

牛马办公的品牌气质是专业、可靠、克制、有温度并带一点职场幽默。它是一款能完成真实工作的办公产品，不使用通用机器人、聊天气泡、魔法棒或炫技式“AI 科技感”作为核心识别。

正式名称：`牛马办公`。英文辅助名暂用 `Niuma Office`，仅用于文件、技术标识或中文空间不足的场景，不替代中文品牌名。

正式 Slogan：`专门替“牛马”干活的 AI 办公工具`。所有官网、客户端和安装包物料必须逐字保持一致。

## 2. Logo

当前图形资产：`../../assets/brand/niuma-mascot-mark-v3.png`。

原始确认母版保存在 `../../assets/brand/source/niuma-doubao-reference.png`；`../../scripts/build-brand-assets.sh` 负责提取最大前景主体、移除背景装饰与水印、生成透明牛头、深石墨色 macOS App Icon 和 `icns`。发布资产不得从聊天临时文件或人工截图重复加工。

Logo 直接采用用户确认的豆包黄色牛形象作为母版，只保留牛本体。识别要素包括：

- 黄色牛头：直接对应“牛马办公”，在小尺寸下仍有明确轮廓。
- 淡定而会意的表情：表达可靠、聪明和懂职场，而非卖萌或戏谑。
- 棕色牛角、横向耳朵与圆润轮廓：形成稳定的小尺寸识别。
- 不添加耳麦、电路线、星光、完成勾、文字、水印或其他背景元素。

透明 PNG `niuma-mascot-mark-v3.png` 用于客户端和官网品牌位。macOS App Icon 使用 `niuma-app-icon-v3.png`：同一牛头置于深石墨色圆角底板上，保证 Dock、访达和浅深壁纸中的边界与对比，不使用完全透明的应用图标。`icns` 必须从该 App Icon 母稿生成。不同页面不得自行重绘或改变表情、比例与颜色。

## 3. 品牌颜色

| Token | 色值 | 用途 |
|---|---|---|
| `brand-mascot` | `#FFC526` | 仅用于 Logo 和同源品牌插图，不作为大面积控件色 |
| `brand-ink` | `#241A12` | Logo 线条、字标和深色背景 |
| `control-primary` | `#202020` | 客户端主要按钮、选中态文字和关键操作 |
| `control-primary-hover` | `#000000` | Hover 与按下状态 |
| `control-selected` | `#E3E3E3` | 导航、列表与分段控件的灰阶选中背景 |
| `surface` | `#FFFFFF` | 主内容背景 |
| `surface-muted` | `#F6F7F9` | 侧栏和次级区域 |
| `text-primary` | `#171A21` | 正文与标题 |
| `text-secondary` | `#626875` | 次级说明 |
| `border` | `#E3E6EB` | 分隔与边框 |

成功、警告、错误和信息色属于产品状态色，不从 Logo 颜色机械推导；必须满足 WCAG 2.2 AA。客户端除 Logo 和必要状态色外只使用黑白灰，不能用蓝色、绿色或黄色表达普通导航选中和常规按钮。

## 4. 字标与使用规则

- 中文字标使用正式授权的系统或品牌字体排版，不让图像生成模型生成文字。
- 图形与字标必须保留安全空间；不得拉伸、旋转、描边、加阴影、改渐变或与其他图标拼接。
- 小尺寸优先使用纯图形；正文中首次出现可使用“图形 + 牛马办公”。
- 客户端、官网、DMG、安装界面、更新器和帮助中心必须使用同一版本资产。
- 第三方渠道头像需在真实圆形裁切与深浅背景中检查，不得因裁切丢失牛角或耳朵。

## 5. 品牌验收

- 16、20、32、64、128、512 和 1024 像素下牛角、眼神与口鼻轮廓仍可识别。
- 浅色、深色、单色和灰度环境中均可识别。
- macOS App Icon 符合当前 Apple 图标规范，菜单栏版本为清晰的模板图标。
- Logo 与官网/客户端的颜色、字标和图标来源一致，没有 WorkBuddy 绿色或第三方品牌资产。
